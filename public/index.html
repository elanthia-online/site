Elanthia Online

Open-source tools, scripts and front ends for the Simutronics games GemStone IV and DragonRealms.

Elanthia Online on GitHub

Projects

  • Lich 5

    GemStone IV and DragonRealms

    The scripting engine. Lich runs between the game and your front end, and gives scripts a Ruby runtime and a shared library to build on.

  • Shared scripts

    GemStone IV and DragonRealms

    Community Lich scripts, mostly for GemStone IV, plus the core scripts that ship with every Lich install.

  • dr-scripts

    DragonRealms

    A curated set of Lich scripts for DragonRealms, from hunting and crafting to training and travel.

  • ProfanityFE

    GemStone IV and DragonRealms

    A terminal front end built on Ruby and ncurses. It connects through Lich.

  • Lichborne

    GemStone IV and DragonRealms

    A community-driven game client, built for people who already play with Lich.

  • Player Shops

    GemStone IV

    Search the items for sale in GemStone IV player shops.

  • Hunting analytics

    GemStone IV

    A dashboard for the analytics.lic script: hunts, silver, experience, kills and bounties. It reads your own database in the browser and uploads nothing.

  • Lich 5 API docs

    For script authors

    Generated reference for the Lich 5 API, for browsing what is available before you start a script.
